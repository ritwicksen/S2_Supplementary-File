This MATLAB script models H⁺ diffusion in a clinopyroxene grain within a non-isothermal, finite-grain system.
User inputs: initial cpx H2O (C0); final cpx H2O (Cf); grain size; activation energy (Ea) and pre-exponential factor (D0).
The script also plots measured H₂O concentrations along core-rim transects.
Diffusion envelopes are generated at user-specified time steps by varying C₀ and SIMS half-length profile within its mean ± 1σ range.
